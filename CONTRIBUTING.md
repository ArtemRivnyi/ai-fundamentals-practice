# Contributing to AI Fundamentals Practice

Thank you for contributing!

## 🚀 Guidelines

1. Ensure Python dependencies are installed:
   ```bash
   pip install -r requirements.txt
   ```
2. Jupyter Notebook standards:
   * Restart kernel and run all cells before committing.
   * Clearly explain mathematical and theoretical intuition in Markdown cells.
   * Set fixed `random_state` seeds for reproducibility.
